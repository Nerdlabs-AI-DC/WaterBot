# Contributing to WaterBot

Thank you for your interest in contributing to **WaterBot**! This project is built with a **Python** backend and a **HTML** frontend, and is designed to run on **Linux**. We welcome contributions of all kinds, including bug fixes, new features, documentation, and support for additional platforms and AI providers.

By contributing, you help make WaterBot better for everyone. Please take a moment to review this guide before getting started.

---

## **How to Contribute**

We accept contributions in the following areas:

- **Bug fixes**
- **New features**
- **Documentation writing**
- **Support for Windows and macOS**
- **Integration with more AI providers**

---

## **Getting Started**

### **Prerequisites**

- **Python 3.10+**
- **pip**
- **venv**
- **Any Linux distribution** (kernel 6.1+ tested and confirmed working)

### **Setup**

1. Clone the repository:
  ```bash
    git clone https://github.com/Nerdlabs-AI-DC/WaterBot.git
    cd WaterBot
  ```
2. Install dependencies:
  ```bash
    chmod +x install.sh
    ./install.sh
  ```
3. Start Waterbot:
  ```bash
    waterbot
  ```

## **Reporting Issues or Requesting Features**

### **Where to Report**

- **GitHub Issues**: https://github.com/Nerdlabs-AI-DC/WaterBot/issues
- **Nerdlabs AI Discord Server**: https://discord.gg/rkSKtdW99R

### **What to Include**

When reporting a bug or requesting a feature, please provide:

- A **detailed description** of the issue or feature request.
- **Steps to reproduce** the issue (if applicable).
- Any additional context, such as:
  - Your operating system and version.
  - Python version.
  - Screenshots or logs (if relevant).

---

## **Submitting Pull Requests (PRs)**

### **Branching**

1. Fork the repository on GitHub.
2. Create a new branch for your changes:
  ```bash
   git checkout -b feature/your-feature-name
  ```
  &nbsp;

### **Coding Guidelines**

- Keep your changes **focused and modular**.
- Include **comments** where necessary to explain complex logic.
- Ensure your code **does not break existing functionality**.

### **Testing**

- Test your changes locally to ensure they work as expected.
- If you add new features, include **basic tests or validation** where possible.

### **Submitting Your PR**

1. Push your branch to your fork:
  ```bash
   git push origin feature/your-feature-name
  ```
2. Open a **Pull Request** on the [WaterBot repository](https://github.com/Nerdlabs-AI-DC/WaterBot) to the `master` branch.
3. Provide a **clear title and description** for your PR:
  - Explain what your PR does.
  - Reference any related issues (e.g., "Fixes #123").
  - Include screenshots or logs if your changes affect the user interface or behavior.

### **Review Process**

- PRs will be reviewed by the **project maintainers**.
- You may be asked to make changes or provide additional information.
- Once approved, your PR will be merged into the `master` branch.

---

## **Releases**
- New versions of WaterBot are released by **tagging the `master` branch** with a semantic version (e.g., `v1.0.0`).
- Releases include all merged features and fixes up to that point.
- Contributors will be credited in the **release notes** for their merged PRs.
