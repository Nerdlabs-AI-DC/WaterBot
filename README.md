# WaterBot
[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/E1E61JZM90) [![](https://dcbadge.limes.pink/api/server/rkSKtdW99R)](https://discord.gg/rkSKtdW99R)

WaterBot is an all-in-one software for creating, managing, and hosting your very own AI Discord bots!

Whether you want a fun chatbot to spice up your server, a helpful assistant to help your community, or a specialized AI tool for a specific task, WaterBot makes it simple to bring your idea to life without needing to code.
## Features
### User-Friendly Design
WaterBot is designed with ease of use in mind.

The clean, modern interface makes creating and managing bots a easy, even if you don't know how to code.

The dashboard provides quick access to bot status, start/stop controls, logs, statistics, and settings.
### Great Customizability
You can tweak everything from the system prompt and personality to advanced memory and behavior settings.
### Multiple AI Providers
WaterBot currently supports OpenAI, OpenRouter, and Ollama for local AI hosting, with more providers on the way.
### Local & Secure
WaterBot runs entirely on your devices, whether it’s your personal computer or a powerful server.

This means you’re not depending on external servers, and your important information stays safe on your own hardware.
### Performance Monitoring
Keep an eye on CPU usage, memory usage, engagement metrics, growth statistics, and overall system status directly from the dashboard.

Detailed logs also make debugging easy.
### Many Use Cases
Use them for casual chatting, productivity tools, customer support, private assistants, server utilities, or fully custom AI experiences for a specific purpose.
## Getting started
1. **Clone the repository**
   ```
   git clone https://github.com/Nerdlabs-AI-DC/WaterBot.git
   cd waterbot
   ```

2. **Run the installer**
   ```
   chmod +x install.sh
   ./install.sh
   ```

3. **Start WaterBot**
   ```
   waterbot
   ```
