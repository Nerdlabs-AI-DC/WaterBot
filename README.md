# WaterBot
WaterBot is an all-in-one platform for creating, managing, and hosting your own personalized AI Discord bots.

Whether you want a fun chatbot for your server, a helpful assistant for your community, or a purpose-specific AI tool, WaterBot makes it easy to bring your idea to life with no coding required.
## Features
### User-Friendly Design
WaterBot is built with simplicity in mind.

The clean, modern interface makes creating and managing bots easy, even for beginners.

The dashboard gives quick access to bot status, start/stop controls, logs, statistics, and settings.
### Great Customizability
Customize everything from the system prompt and personality to advanced memory and behavior settings.
### Multiple AI Providers
WaterBot currently supports OpenAI, OpenRouter, and Ollama for local AI hosting, with more providers planned in the future.
### Local & Secure
WaterBot operates entirely on your own devices, whether it’s your personal computer or a powerful server.

This means you’re not relying on external servers, and your important information remains secure on your own hardware.
### Performance Monitoring
Track CPU usage, memory usage, engagement metrics, growth statistics, and overall system status directly from the dashboard.

Detailed logs also make debugging much easier.
### Many Use Cases
Use them for casual chatting, productivity tools, customer support, private assistants, server utilities, or fully custom AI experiences built for a specific purpose.
## Getting started
1. **Clone the repository**
   ```
   git clone https://github.com/Nerdlabs-AI-DC/WaterBot.git
   cd waterbot
   ```

2. **Run the installer**
   ```
   chmod +x install.sh
   ./install.sh
   ```

3. **Start WaterBot**
   ```
   waterbot
   ```
